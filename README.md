# PIXEL SURVIVORS v2 — 토토의 잃어버린 숲

## 세계관
주인공은 길을 잃은 작은 고슴도치 **토토**입니다. 밤이 되면 숲의 기억이 조각나고, 그림자 생물들이 그 조각을 차지하려고 몰려옵니다. 토토는 반딧불이의 기억 조각을 모아 숲길을 밝히고 집으로 돌아가야 합니다. 경험치는 **기억 조각**이며 레벨업은 토토가 숲의 생존법을 되찾는 과정입니다.

## 실행
1. ZIP 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge에서 엽니다.
3. 선택 사항: 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

## 조작
- 이동: WASD / 방향키
- 일시정지: P
- 공격: 자동
- 레벨업: 3개 강화 중 하나 선택

## 무기 및 아이템
- **관통 화살:** 자동으로 적에게 발사되며 기본 2명을 관통합니다. 정밀 깃촉은 피해, 관통촉은 관통 수, 매의 깃털은 발사 간격을 개선합니다.
- **수호 칼날:** 토토 주위를 돌며 닿는 적에게 피해를 줍니다. 칼날 추가와 피해 강화가 가능합니다.
- **버섯 포자:** 해금 후 주기적으로 주변에 원형 폭발을 일으켜 무리 정리에 유리합니다.
- **폭풍 병:** 해금 후 체력이 높은 적에게 번개를 내리고 주변 적에게도 연쇄 피해를 줍니다.
- **에너지 드링크:** 이동 속도 증가.
- **반딧불이 자석:** 기억 조각 흡수 범위 증가.
- **달콤한 꿀단지:** 체력 회복.
- **도토리 갑옷:** 최대 체력 증가 및 회복.

## 파일 구조
- `index.html`: 화면, 메뉴, 인게임 경험치 게이지
- `styles.css`: UI 스타일
- `game.js`: 게임 루프, 무기, 적, 충돌, 경험치, 레벨업
- `README.md`: 설명과 실행 안내
